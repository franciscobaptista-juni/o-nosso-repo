Calendário de prioritização

Ferramenta para consultores da JUNITEC que planeiam projectos de desenvolvimento. Junta developers (com as suas skills) e tarefas com duração e a app sugere a ordem e a atribuição que conclui o projecto mais cedo.

Developers

Descreve as skills de cada developer, separadas por vírgulas (por exemplo: Frontend, Testes). Aparecem depois como opções nas tarefas.

Tarefas

Dados de exemplo, só para ilustrar. Tudo fica guardado neste browser (localStorage). Cada tarefa pode depender de uma tarefa anterior e pedir uma skill: nesse caso só vai para developers que a tenham.

Início do projecto

Só contam dias úteis (segunda a sexta). Se indicares um prazo, a app diz se o projecto chega a tempo.

    Regra: entre as tarefas prontas a começar, avança primeiro a que bloqueia mais trabalho a seguir (caminho crítico). Cada tarefa vai para o developer que a termina mais cedo.
